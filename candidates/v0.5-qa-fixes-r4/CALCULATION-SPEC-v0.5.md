# v0.5 staged calculation and evidence specification

Status: **not validated against the game designer; not a release acceptance**. Scope and labels below describe the staged candidate. Do not expose a derived value as a game result until matched-version, DLC, equipment, technology, modifier and rounding fixtures establish its behavior.

| Feature | Inputs and units | Available behavior | Boundary / evidence |
| --- | --- | --- | --- |
| Template editor | Unit IDs and nonnegative integer counts; army count 1–10,000 | Rejects an empty/all-zero template, duplicate active unit IDs, ambiguous or missing active unit IDs, counts over 25 per row, more than 25 line units or five support units. Saves the existing profile template schema. | Checks are app input rules, not proof of designer layout, special-forces restrictions or in-game legality. A template is not automatically a legal division. |
| Composition comparison | Current draft and one saved template from the active profile | Displays counts of each unit type side by side; no combat calculation or asynchronous comparison call. A comparison is scoped to profile ID, saved name, exact rows and index revision. | It disappears if the saved rows, profile, or index change or the template is deleted. Counts are the user's inputs, not designer statistics. |
| Division calculations | Unit counts and army size | Unavailable. The public `/calculate` endpoint returns 503; `/template-validation` returns only a validation status. | Width, manpower, supply, organization, equipment requirements, armor, piercing and all derived statistics require matched in-game fixtures and rounding checks. Legacy internal arithmetic is retained for source-research tests only and is not a supported result. |
| Equipment comparison | Two installed indexed equipment definitions | Shows raw indexed declarations and a decimal difference (second minus first), preserving round-trip input precision. Values carry entry, file, line, hash, game version and index revision. | Archetype override is an extraction interpretation, not verified engine behavior. Missing/ambiguous/cyclic chains withhold results; duplicate-archetype transforms are not evaluated. Modules, equipment designer choices, technologies and campaign modifiers are excluded. Missing values are unknown, not zero. |
| Equipment differences | Two finite declared numeric values in the same raw stat | Decimal difference is computed from their round-trip decimal representations. A missing or non-finite value gives unknown. IC cost is IC/item; reliability and hardness are fractions; speed is km/h. Other values retain the declared game-stat unit. | Arithmetic compares declarations, not effectiveness, final designer values or applicability. Different categories can be incomparable. |
| Production estimate | Equipment, stockpile, factories and efficiency | Unavailable; `/production` returns 503. | Earlier constant-efficiency IC/day = base IC × factories × efficiency × output factor × resource factor, and days = ceiling(shortage × cost / IC/day), remain research-only formula candidates. In-game output and rounding parity are not established; naval dockyard production is unsupported. |
| Technologies / doctrines / modifiers | Potential selections and scenario assumptions | Unavailable. | No unverified stacking, national modifiers, equipment-derived effects, doctrine or designer effect is applied. Manual percentages from the earlier partial candidate were removed because their base division statistics are unavailable. |
