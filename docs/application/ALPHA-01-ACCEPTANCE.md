# ALPHA-01 owner walkthrough

This unsigned isolated Windows development alpha connects Campaign-first planning to the existing local service. Extract the whole ZIP into a new folder and open the executable inside `win-unpacked`, keeping its resources beside it. BUILD.json identifies the source. The build uses its own development data directory and does not replace an installed Companion or older builds. First indexing may take up to two minutes; do not launch HOI4 to troubleshoot it.

1. Open **Campaign**, then **Create / select campaign**. Create Germany or select saved Germany work. New campaigns default to the owner's all-DLC configuration; review declared exceptions before saving. Existing campaigns retain their declarations. This alpha's source-only check used installed patch **1.19.5.0**, current `german_focus` in `common/national_focus/germany.txt`, rather than the legacy German tree. The home displays your actual indexed patch and selected tree. If necessary use **Set up focus tree**, choose the current tree in the existing planner, review and Apply; return to Campaign.
2. Ask for preparation toward a possible 1941 eastern campaign. **Send question locally** asks for missing high-impact context. Supply current date/route, research/production/forces, timing and role in **Shared manual campaign context**. Unknowns may remain unknown; label historical information and exceptions to all DLC/no mods.
3. **Build provisional preparation locally** gives an editorial checklist, without a model request or numerical readiness claim. Read its assumptions/uncertainty, then **Expand editable strategy**. Name it, edit recommendations, references and conditions, and add only source-supported focuses. Source applicability and readiness remain provisional.
4. **Preview AI source bundle** uses the real local source selection and spending quote. Inspect omissions, sources, requirements, costs and the separate character/byte budgets. Without an API key the editor stays usable. The quote/transmission checkboxes approve a separate paid action; this walkthrough does not authorize clicking Generate. Provider credentials last only for the service session.
5. Open **Compare preparation compositions**, enter both proposed mixes and assumptions, and inspect a selected unit source. The current-patch qualification refusal is expected. Manual tradeoff questions remain usable; attack, defense, organization, breakthrough, cost and a winner are unavailable. Edits invalidate the inspection. A paid strategy revision always requires a fresh preview and separate approval.
6. Visit **Tools** and another tool, then return to Campaign/Chat. Objective, manual context, proposal and comparison text remain in this window. Switch campaigns and confirm each shows its own conversation/draft. **Saved** reopens the same saved strategy model; it does not create a duplicate.
7. Choose **Save and recheck strategy**. This runs the existing coverage review and writes a named revision. Edit and save another revision if desired. Conversation records the strategy identity/revision. Coverage gaps keep advice provisional; source-valid ordering never establishes readiness or optimality.
8. Close and reopen the app. In Saved, reopen the strategy and expand it. Confirm the objective, shared context, composition and latest revision, and the campaign conversation. Saved work is durable. Unsaved strategy work is in-window only: save or download before closing. A failed conversation save offers retry/download/discard; pending writes protect closing. Conversation history is bounded to 160 entries; download before continuing in a new campaign.

Record owner acceptance as accepted, accepted with named limitations, changes requested, or pending. Fixture/synthetic campaigns validate engineering only. A real-provider usefulness test waits for the owner's explicit displayed-quote approval after the candidate is ready; at most one generation, retain failed output/usage, repair locally and no automatic paid retry. No HOI4 launch/gameplay is authorized. Final release, explanation coverage, QUAL-195, combat, native and broader usefulness gates remain intact.
