# Milestone 7.1 desktop acceptance

Extract the entire M7.1 ZIP into a new folder. Open `win-unpacked/HOI4 Companion M7.1-<commit>.exe`; keep the EXE beside all its resources. Do not copy it over an older companion or run it inside the ZIP. This unsigned development build does not install or update an application. Its normal data is separate under `%APPDATA%/HOI4 Companion Development/M7.1-<commit>/`.

1. Open **Sources & settings**. Confirm the detected HOI4 folder and version, then let reference indexing finish. This reads installed files. The laptop audit used **1.19.4.2**; a different desktop patch can have different definitions. Do not change your playset, mods or saves for this review. Existing mod-merge limitations still apply.
2. In **Campaign planner**, create or open a disposable planning workspace. Open **Look up decisions and technologies**, choose **Decisions**, then **All countries**. Search `BEL_EU_`. Results should form one readable column. Expansion decisions should explain conditional annexation and cores after the 70-day active period. Their conditions are source rules, not a claim that your campaign can take them.
3. Search `BEL_emergency_measures_on_production_front`. Expect 100 base political power, a 180-day national spirit, factory output **+25%**, and civilian/military factory construction speed **-15%**. Expand **More effects, requirements and limitations** to inspect requirements and any unsupported category scripting.
4. Search `AUS_industrial_coaxing_decision`. Expect 100 base political power, **3 civilian factories committed for 50 days**, then an event for the selected country after **12 hours** when the decision is removed. The selected target and campaign-dependent event name remain unknown. No actual factories are assigned by the companion.
5. Search `AUS_recruitment_push`. Inspect its custom command-power requirement; the app must not describe that predicate as proven spending. The 365-day idea lists weekly manpower **+100** and mobilization law cost **-25%**. Division templates/random unit placement remain unsupported.
6. Change type to **Technologies**, search `basic_machine_tools`, and check production efficiency cap **+10%**. Open its full reference. Names, effects and numeric units should agree across the list and details. **Advanced technical source** exposes identifiers, source path, hash and raw source only when expanded.
7. Use Tab/Enter to open a result and Escape to close its dialog. Resize the window. Check that text remains readable without horizontal scrolling; report desktop scaling or keyboard problems with the build label.
8. Try universal search for `Dutch East Indies`, `INS`, a focus, a decision and a technology. Confirm result categories. Open a focus objective in the planner, compare two disposable alternatives, save, close and reopen the app. Verify the saved workspace and alternatives persist.
9. Optional history review: import the bundled `M65-HISTORICAL-OBSERVATIONS.jsonl` in **Command center → Your observed campaign**. These are eight retained M6.5 observations, not your current desktop campaign. Select the saved recording after restarting. Do not manufacture JSON or edit a personal save. Do not apply an imported baseline to an existing workspace; the reviewed transfer creates a new one.

Please record the search/identifier, expected versus actual wording, source version, build label and screenshot for any problem. Unsupported scripting and unavailable campaign state are intentional distinct labels; report misleading claims or missing meaningful outcomes, not merely the presence of a limitation.

If startup fails, retain this build's `diagnostics` folder under its isolated data directory. A missing installation is a Sources & settings problem; do not repeatedly launch HOI4. For source developers, `npm run browser` uses the same renderer/service but your system browser and checkout environment rather than this bundled Electron runtime and isolated build profile. The packaged app requires neither Node nor npm on the desktop.

This review does not qualify live telemetry, save mappings, gameplay control, full accessibility or all game mechanics. No HOI4 launch is needed.
