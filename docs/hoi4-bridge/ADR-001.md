# ADR-001: extend the companion service; separate observation from control

Date: 2026-11-04. Accepted for the first milestone.

The verified checkout is `connorgreenleaf22/hoi4-companion`, branch `feature/hoi4-bridge`, baseline `ba4c3c9`. The selected chat directory was empty; implementation uses the existing checkout. No migration, history replacement or new branch is needed. There were no repository AGENTS.md or skills before this work.

The actual application uses React 19, TypeScript, Vite, Electron 45, Node's built-in HTTP server and `node:sqlite`. Reuse its ordered Clausewitz parser, installed-reference index, source hashes, ambiguity resolution, host/origin protection and QA fixtures. Add `/api/v1/bridge/*` on the existing listener and a CLI path through `server/cli.ts`. Bridge persistence uses a separate `bridge.sqlite` in the same configured application data directory to avoid changing the campaign schema or its release/migration gates. No new runtime dependencies.

Observer is the default. Telemetry is an explicit log reader plus an additive mod with a unique on-action file. The first producer observes GER once daily; it does not alter political power, stability, focus, research, AI or other mechanics. Achievement eligibility is unverified. Records are one-way, versioned and terminated. Engine log prefixes supply game time; the host supplies version and log-generation identity. This is not a full live-state API or a bidirectional command channel.

Control is a separately gated adapter contract. No production adapter is registered. Actions use a durable write-ahead receipt, exclusive SQLite reservation, server-side authorization, expected session/version/snapshot checks, independent readback and bounded deadlines. A timed-out adapter retains the exclusive reservation until it settles; a crash leaves an uncertain receipt and reservation requiring explicit reconciliation. There is no automatic retry or queue. Pause/resume are reserved capability names, not advertised native functionality.

## Existing QA findings
